# Реестр данных Apollon

Этот файл — единый рабочий реестр расчётов, источников и границ интерпретации.
Он нужен для аудита: модель не должна использовать поле, если оно не рассчитано,
не имеет источника или относится к другой смысловой кнопке.

## Исполняемый контур

| Слой | Где находится | Роль |
|---|---|---|
| Методология и стиль | `CLAUDE.md` → `SYSTEM_PROMPT` в `bot.py` | Общие правила ответа и ограничения |
| Расчёты | `server.py` | Натальная карта, HD, транзиты, соляр, лунар, циклы, HD-связи пары |
| Библиотека смыслов | `hd_library.py` | Подбор подтверждённых фрагментов HD-библиотеки |
| Геокодирование | `bot.py:parse_city` | Координаты города и часовой пояс |
| Сессия пользователя | SQLite / Railway Volume `/data` | Сохранение карты, имени и истории блоков |
| Формулировка | Anthropic API | Только редакционная интерпретация переданных фактов |
| Упаковка себя и продуктов | `brand_data` в SQLite + опросник в `bot.py` | Сохраняет опыт, продукты, цель, ответы и архетипическую гипотезу |

## Источник → поле → допустимое использование

| Поле | Источник | Статус | Кнопки |
|---|---|---|---|
| Тип, стратегия, авторитет | `hd_types_authority.md` | Есть; редкие авторитеты требуют сверки | Все личные блоки |
| Профиль | `PROFILE_DESCRIPTIONS` в `hd_library.py` | 8 из 12 профилей; пробелы нельзя заполнять догадкой | Характер, предназначение, отношения |
| Центры | `hd_centers.md` + расчёт `server.py` | Есть | Характер, отношения, деньги, здоровье, ресурсы |
| Каналы и ворота | `hd_channels_gates.md` + канонический список в `server.py` | Расчёт есть, локальный текст неполный | Только при наличии описания |
| Линии | `hd_lines_all_gates.txt` | Рабочий перевод Line Companion, подтверждённый пользователем | Все блоки при наличии фрагмента |
| Крест | `hd_incarnation_cross.txt` + четыре оси в `server.py` | Требует проверки всех четырёх активаций | Предназначение |
| Переменные/PHS | `hd_phs_index.txt`, `hd_phs_variables.txt` | Есть; Base пока без словаря | Ресурсы |
| Любовные ворота | `hd_love_book.txt` | OCR требует ручной проверки | Отношения |
| Западная астрология | Swiss Ephemeris в `server.py` | Расчётный слой | Все блоки и прогнозы |
| География рождения | Локальный словарь + Nominatim | Для неизвестных городов возможна погрешность часового пояса | Все карты |

## Астрологические ограничения

Рассчитываются: тропический зодиак, Плацидус, планеты, узлы, все 12 домов,
куспиды, традиционные управители и мажорные аспекты.

Пока не считать фактом: Парс Фортуны, атмакараку, D-10, даши, автоматические
ингрессии, станции, пики, applying/separating и точные моменты разворота, если
они не были отдельно рассчитаны.

## Совместимость

HD-слой считается детерминированно: общие каналы, электромагнитные связи,
компромиссы, доминирование, составные каналы и центры. Психологический смысл
не вычисляется автоматически и берётся из библиотеки.

Полная астрологическая синастрия пока не завершена: не рассчитаны взаимные
аспекты, планеты в домах партнёра и композитная карта. До завершения этого
слоя результат нельзя называть полной синастрией.

## Правило качества

Каждый абзац проходит цепочку:

`расчёт → источник → наблюдаемая тема → человеческая формулировка`.

Если поле отсутствует, источник не найден или точность времени недостаточна,
бот должен явно сказать об ограничении, а не подменять его общей фразой.

## Пробный доступ

Стандартный пробный период — `TRIAL_DAYS=3` (72 часа с момента согласия на
обработку данных). Дата начала хранится в SQLite в поле `trial_started` и не
сбрасывается повторным `/start` или `/reset`. До подключения оплаты используется
мягкий режим `TRIAL_ENFORCED=0`: бот показывает оставшийся срок, но не блокирует
пользователя. После появления оплаты можно включить `TRIAL_ENFORCED=1` в Railway.

Для тестового открытия платного ИИ-редактора используется список
`PREMIUM_USER_IDS`. Реальную оплату и автоматическую выдачу доступа нужно
подключить отдельно; до этого бот честно показывает, что функция находится в
PRO-версии.
